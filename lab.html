Synth-2

The current work, and the first one that carries the idea in its architecture rather than in its training data: an epistemic head on every layer predicts the model's own error per token, so the answer can show which span to check. It reads a search results page and answers only from it.

Sane Studio

A desktop agent for Windows that does the work on your own machine, with your own model keys.

What it does while you are busy

01Edits a project and runs commands in it
02Clicks buttons on websites experiment
03Answers out loud when called by name experiment
04Answers from your own folders
05Reachable from a phone, through Telegram
06Runs tasks on a schedule
07Any model, your own API keys

How it ships

The app and its website read one manifest, so a release cannot leave them disagreeing: the installer checks it daily, compares versions and verifies the download against its sha256.

Free to use, with paid tiers for the parts that save hours rather than minutes.
